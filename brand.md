# MANDATE brand system

## Direction: Graphite Proof

MANDATE should feel like an institutional execution terminal made approachable: calm, exact, evidence-led, and never theatrical. The product earns trust through visible limits, source labels, and receipts—not through futuristic decoration.

## Color

- `Ink / #11110F`: primary text and dark surfaces
- `Graphite / #1A1A17`: navigation and high-emphasis panels
- `Paper / #F4F1E8`: application background
- `Warm white / #FFFCF4`: cards and form surfaces
- `BNB yellow / #F3BA2F`: primary actions and verified onchain state only
- `Sage / #397358`: positive, within-limits state
- `Oxide / #A14A3A`: destructive or violated state
- `Stone / #77736B`: supporting copy
- `Rule / #D8D2C4`: borders and separators

No gradients. Yellow must remain scarce so it continues to mean “act” or “verified”.

## Typography

- Display and interface: `Inter`, falling back to system sans-serif
- Evidence, addresses, figures, hashes: `IBM Plex Mono`, falling back to system monospace
- Use tabular numerals for all comparable financial values.

## Shape and depth

- 2–4px radii for controls and cards; avoid bubbly containers.
- 1px warm-grey rules carry most hierarchy.
- Shadows are restrained and only indicate a raised actionable surface.
- Dense tables on desktop collapse to horizontally scrollable evidence blocks on mobile.

## Voice

Short, factual, and reversible. Prefer “Preview transaction”, “Within your limit”, and “No transaction broadcast” over promotional claims. Every important number should expose whether it is `ONCHAIN`, `DERIVED`, or `PREVIEW`.

## Motion

Motion explains state transitions only: shadow-run progress, transaction preparation, and completion. Default duration is 160–240ms. Respect `prefers-reduced-motion`.
